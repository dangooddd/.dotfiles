# **dangooddd's** dotfiles

> Unix systems only!

## Installation

Clone repository:

```sh
git clone https://github.com/dangooddd/.dotfiles.git
```

Install dotfiles:

```sh
cd .dotfiles
scripts/setup-arch.sh
# scripts/setup-macos.sh
# scripts/setup-dev.sh
```
